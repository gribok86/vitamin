# Vitamin API

Простой REST API для валидации и учёта витаминов и микроэлементов. Написан на **FastAPI**, работает локально.

## 📋 О проекте

**Vitamin API** — это учебный проект, который принимает список витаминов и минералов, проверяет их корректность и сохраняет историю запросов. API поддерживает как русские, так и английские названия, а также их сокращения (например, `D3`, `Mg`, `B12`).

Проект создан для демонстрации базовых принципов построения REST API на FastAPI с валидацией входных данных, обработкой ошибок и ведением истории.

## ✨ Возможности

- **Приём и валидация витаминов** — проверка на допустимые названия, длину строки и количество элементов.
- **Поддержка русского и английского** — названия витаминов распознаются в обоих языках.
- **История запросов** — каждый успешный запрос сохраняется с уникальным номером.
- **Защита от некорректного ввода** — отсеиваются подозрительные символы и недопустимые названия.
- **Автоматическая документация** — FastAPI генерирует Swagger UI и ReDoc.

## 🛠️ Технологии

- **Python 3.10+**
- **FastAPI** — веб-фреймворк
- **Uvicorn** — ASGI-сервер
- **Pytest** — тестирование

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/gribok86/vitamin.git
cd vitamin
```

### 2. Установка зависимостей

```bash
pip install fastapi uvicorn pytest
```

### 3. Запуск сервера

```bash
python main.py
```

Сервер запустится на `http://127.0.0.1:8000`.

После запуска откройте:

- **Swagger UI**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **ReDoc**: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

## 📡 Использование API

### `POST /add_vitamins` — добавить витамины

Принимает строку с витаминами, разделёнными пробелами или запятыми.

**Пример запроса:**

```bash
curl -X POST "http://127.0.0.1:8000/add_vitamins?vitamins=D3,%20Mg,%20B12"
```

**Успешный ответ:**

```json
{
  "result": ["d3", "mg", "b12"]
}
```

**Возможные ошибки:**

| Код | Сообщение | Причина |
|-----|-----------|---------|
| 404 | `Ошибка: '...' не является допустимым витамином.` | Название не найдено в списке |
| 404 | `Вы ввели не витамины` | Пустой список после очистки |
| 200 | `{"Error": "Строка с витаминами пуста"}` | Пустая или пробельная строка |
| 200 | `{"Error": "Вы ввели больше 10 витаминов за раз"}` | Превышен лимит в 10 элементов |
| 200 | `{"Error": "Вы передали больше 35 символов"}` | Длина строки превышает 35 символов |
| 200 | `{"Error": "Не балуйся"}` | Обнаружены недопустимые символы |

### `GET /history` — история запросов

Возвращает все успешные запросы с их порядковыми номерами.

**Пример запроса:**

```bash
curl http://127.0.0.1:8000/history
```

**Пример ответа:**

```json
{
  "user_history": [
    {
      "number_of_request": 1,
      "request": ["d3", "mg", "b12"]
    }
  ]
}
```

## 🧪 Тестирование

Проект содержит базовый тест. Запуск:

```bash
pytest tests/test_vitamin.py -v
```

Тест проверяет корректность обработки строки `"D3, , Mg"` — ожидается результат `["d3", "mg"]`.
